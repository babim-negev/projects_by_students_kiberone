# danila-n — расписание на день / неделю / месяц

Простое веб-приложение на **FastAPI**: свои события, **SQLite** (один файл, без Postgres), вход по логину/паролю, сессия **14 дней** через cookie и JWT.

## Что установить один раз

Нужен **Python 3.10+**.

```bash
cd danila-n
python3 -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Открой файл **`.env`** и поменяй **`SECRET_KEY`** на свой длинный случайный набор символов (от него зависит подпись «куки входа»).

## Запуск сайта

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

В браузере открой: **http://127.0.0.1:8000**

Если терминал пишет, что адрес уже занят, бери другой порт:

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

## Как пользоваться сайтом

### 1. Регистрация или вход

- Открываешь главную страницу — перебросит на **«Вход»**.
- Если первый раз: нажми **«Зарегистрироваться»**, придумай **логин** (от 2 символов), **пароль** дважды (минимум 4 символа).
- Если аккаунт уже есть — введи логин и пароль и нажми **«Войти»**.

После входа ты попадаешь на экран **одного дня** с твоими событиями.

**Альтернатива (для учителя/скрипта):** пользователя можно создать командой без сайта:

```bash
python scripts/create_user.py danila мойСекрет123
```

Такой пользователь затем просто входит через форму **«Вход»**.

### 2. Шапка сайта

Сверху ссылки:

- **День** — список дел на выбранную дату; стрелки «вчера / сегодня / завтра».
- **Неделя** — всё между понедельником и воскресеньем недели (можно перелистать недели).
- **Месяц** — всё за выбранный календарный месяц.
- **+ Событие** — форма добавления.

Справа: твой **логин** и ссылка **«Выйти»** (удалит cookie входа).

### 3. Добавить событие

1. Открой **«+ Событие»**.
2. Поле **«Название»** — например «сделать уроки».
3. **«Начало» и «Конец»** — это поля браузера **дата + время**.
   - Важно: нужно указать **и день, и время**. Если где-то висит только дата и время **`--:--`**, браузер показывает ошибку *«поле не заполнено или недействительная дата»* — нужно щёлкнуть по времени и выбрать часы и минуты (например 16:30).
4. **«Заметка»** — по желанию.
5. **«Сохранить»** — событие появится в списках **День / Неделя / Месяц**, если попадает в этот период.

События хранятся в **твоём** аккаунте; чужие не видны.

### 4. Удалить событие

Рядом с событием кнопка **«Удалить»** — подтверждение в диалоге браузера.

## Если что-то не работает

- **Ошибка у поля даты/времени** — почти всегда не выбрано **время** (осталось `--:--`). Выбери время в том же поле.
- **«Неверный логин»** — проверь пароль; при необходимости зарегистрируй нового пользователя или создай через `scripts/create_user.py`.
- После смены Python — снова `pip install -r requirements.txt`.
