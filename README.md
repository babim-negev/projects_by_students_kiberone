# Проекты Kiber One (Школа программирования)

Здесь лежат **ученические проекти**: разные авторы работают в **разных папках**.

| Папка | Чей проект |
|--------|-------------|
| [`sergey-k/`](sergey-k/) | Серёжа — примеры на **Turtle** |
| [`danila-n/`](danila-n/) | Данила — **веб-расписание** ([гайд по установке и запуску](danila-n/README.md)) |

**Python уже установлен** — достаточно версии с поддержкой **`tkinter`** (он нужен модулю `turtle`). Отдельно ставить «пакет turtle» через `pip` не нужно.

---

## Быстрый старт: проект Серёжи (`sergey-k`)

В терминале:

```bash
cd sergey-k
pip install -r requirements.txt
python examples/01_rainbow_spiral.py
```

Другие скрипты — из той же папки:

```bash
python examples/02_svetloe_kruzho.py
python examples/03_gorod_gorizont.py
python examples/04_kiber_one_lyublyu.py
```

- После запуска откройте окно приложения поверх редактор (на macOS оно может оказаться **позади Cursor** или в Dock).
- Если в программе указано «кликни по окну» — скрипт **ждёт клика** перед выходом.

### Если ошибка `_tkinter` / Turtle не открывается

Подробнее — комментарии в [`sergey-k/requirements.txt`](sergey-k/requirements.txt). Кратко: на macOS часто нужен системный интерпретатор или Python, **собранный с поддержкой Tk** (для pyenv см. установку **`tcl-tk@8`** и пересборку Python 3.11).

## Быстрый старт: проект Данилы (`danila-n`)

Веб-приложение **расписания** (день / неделя / месяц): **FastAPI + SQLite**. Подробно — в **[`danila-n/README.md`](danila-n/README.md)** (как пользоваться сайтом, регистрация, типичные ошибки).

От **корня этого репозитория** (папка, где лежат `danila-n` и `sergey-k`):

```bash
cd danila-n
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Открой .env и впиши свой SECRET_KEY (длинная случайная строка).
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Браузер: **http://127.0.0.1:8000** — дальше **«Зарегистрироваться»** или **«Вход»**.  
Не хочешь регистрироваться в браузере — пользователь из терминала: `python scripts/create_user.py логин пароль` (из папки `danila-n`, с активированным `venv`).
